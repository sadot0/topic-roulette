# Рулетка тем

Барабан, который выдаёт одну тему для короткого видео.
Крутанул → выпала незнакомая тема → 15 минут ресёрча → минута на камеру.

Приложение намеренно не объясняет тему. Оно называет её — и всё.
Объяснять будешь ты, в ролике.

Десктоп. Один файл. Без сборки, сервера и зависимостей.

## Запуск

Открой `index.html` двойным кликом.

## Управление

| Действие | Как |
|---|---|
| Крутить | кнопка или `Пробел` |
| Пропустить вращение | ещё раз кнопка или `Пробел` |
| Запустить ресёрч | кнопка `15 МИН` (активна после спина) |
| Пауза в таймере | `Пробел` |
| Закрыть таймер | `Esc` |
| Язык | `RU` / `EN` / `UZ` в шапке |
| Звук | иконка динамика |
| Длительность таймеров | шестерёнка |
| Сбросить прогресс | `СБРОС` |

Язык, звук, длительности, **выпавшая тема** и список открытых тем
сохраняются в браузере. Перезагрузка не теряет тему — можно спокойно
уходить в другие вкладки ресёрчить.

Во время ресёрча обратный отсчёт дублируется **в заголовке вкладки**:
`14:59 · РЕСЁРЧ`. Оверлей в этот момент не виден, потому что ты читаешь
в соседних вкладках — заголовок остаётся единственной видимой
поверхностью.

## Как этим пользоваться

1. **Крути** — выпадает тема.
2. **Запусти ресёрч** — 15 минут на то, чтобы разобраться. Таймер можно
   поставить на паузу или пропустить.
3. **Начни речь** — сначала отсчёт `3 · 2 · 1`, чтобы успеть включить
   запись и набрать воздух, потом минута на камеру. Экран делится
   на три опоры:

   > **ЧТО?** → **И ЧТО?** → **ЧТО ДАЛЬШЕ?**

   Каждая подсвечивается в свою треть минуты. Это каркас связного
   монолога: сначала что за явление, потом почему это важно, потом
   что с этим делать. Без него минутный ролик обычно разваливается
   на пересказ определения.

Длительности настраиваются: ресёрч 1–60 минут, речь 1–10.

## Как добавить или изменить темы

Темы лежат отдельно от кода — правишь JSON, а не разметку.

1. Открой `seed-topics.json`
2. Добавь или отредактируй объект
3. Пересобери: `node build.js`

```json
{
  "slug": "unique-kebab-case",
  "domain": "tech",
  "era": "modern",
  "ru": { "title": "Коллапс модели" },
  "en": { "title": "Model Collapse" },
  "uz": { "title": "Model kollapsi" }
}
```

**title** — единственное, что видит пользователь. До 4 слов.
Длиннее — кегль автоматически уменьшится ступенью, но лучше не доводить;
сборщик предупредит о заголовках длиннее 32 символов.

**domain** — один из семи: `mind`, `economy`, `society`, `philosophy`,
`systems`, `power`, `tech`. Показывается моно-кодом (`TEC`, `ECO`, …).

**era** — `classic` или `modern`. На экран не выводится, нужна для
баланса набора при пополнении.

Лишние поля (например `hook` из исследовательских батчей) не мешают —
сборщик их просто отбросит.

### Сборка из батчей

Если темы приходят пачками (`topics-batch-0.json`, `-1`, …):

```
node build.js /путь/к/папке
```

Сборщик склеит все батчи, выкинет дубликаты по `slug`, проверит поля
и соберёт `index.html`. Что не прошло — напечатает списком.

## Файлы

```
index.html          ← готовое приложение (то, что открываешь)
app.template.html   ← шаблон: вёрстка, стили, логика
build.js            ← сборщик: шаблон + темы → index.html
seed-topics.json    ← темы
```

`index.html` собирается автоматически — править его руками бессмысленно,
следующая сборка перезапишет. Правь `app.template.html`.

## Что под капотом

**Вращение.** Две фазы вместо одной: разгон проносит ленту почти до цели
(~4.5 с), затем начинается отдельный медленный доползок последних полутора
строк (~2.8 с). Один easing такого «почти взял» не даёт. Итого ~7.5 секунды.

**Звук.** Синтезируется в браузере через Web Audio API — ни одного
аудиофайла. Щелчки привязаны к пересечению границ строк, поэтому
замедляются вместе с лентой физически, а не по таймеру. На остановке —
низкий удар с обертоном, приходящим на 45 мс позже: так звенит металл
после контакта, а не вместе с ним.

Первый звук появится только после первого клика — браузеры запрещают
запускать аудио до жеста пользователя.

**Размытие.** SVG-фильтр с `stdDeviation="0 N"` мылит только по вертикали
и привязан к мгновенной скорости. Обычный CSS `blur()` размазал бы текст
и по горизонтали. Когда лента почти встала, фильтр снимается полностью,
чтобы не держать GPU занятым на статичном слое.

**Выбор темы.** Не `Math.random()`, а shuffle-bag: выдаются все темы без
повторов, потом мешок пересдаётся. Честный рандом повторяется так часто,
что читается как баг, даже когда работает правильно.

**Палитра.** База — сине-фиолетовая чернильная `#0B0D14`, акцент —
тёплое золото `#E3A857`. Это **комплементарная** пара: цвета с
противоположных сторон круга. У референса пара аналогичная (зелёный фон +
терракота) — соседи по кругу дают мало контраста, и акцент вязнет в фоне.
На синем золото светится.

**Шрифты.** Cormorant Garamond 600 для имён и заголовков, Manrope для
интерфейса. Оба поддерживают кириллицу — обязательное условие.
Цифры таймера намеренно набраны Manrope: у Cormorant старостильные
цифры, где «1» мелкая, а «4» и «3» уходят под базовую линию — для
таймера, на который смотрят мельком, это нечитаемо.

**Фон.** Один фиксированный слой: четыре радиальных градиента (золотая
лампа сверху-слева, фиолетовая справа, холодная бирюза снизу) плюс
SVG-зерно в `mix-blend-mode: soft-light`. Обычный `normal`-blend
равномерно серит тёмное, и его приходится глушить до невидимости;
`soft-light` даёт фактуру, не поднимая чёрное.

**Таймер.** Отсчёт идёт против абсолютного дедлайна (`Date.now() + сек`),
а не накоплением дельт. Фоновая вкладка троттлит интервалы, и наивный
счётчик отстал бы на минуты. Пауза запоминает остаток и пересчитывает
дедлайн при возобновлении.

## Чем отличается от unprompted.cool

Референс, с которого снята идея таймеров. Что сделано иначе:

| | unprompted.cool | здесь |
|---|---|---|
| Языки | только английский | RU / EN / UZ |
| Тем в режиме ресёрча | 23 | 66 |
| Пауза в таймере | нет | есть |
| После завершения ресёрча | тупик: нельзя попасть в речь, не перезапустив таймер | прямая кнопка «Начать речь» |
| После минуты речи | только «Закрыть» | «Следующая тема» — цикл без лишних кликов |
| Отсчёт перед речью | нет, таймер стартует мгновенно | `3 · 2 · 1` |
| Отсчёт в заголовке вкладки | нет | есть |
| Тема после перезагрузки | теряется | восстанавливается |
| Пропустить вращение | нельзя | клик или пробел |
| Вращение | 4.8 с, из них ~1.1 с зависания на «не той» теме перед финалом | 7.5 с непрерывного движения, двухфазное торможение |
| Барабан | смена текста на месте | физическая лента с размытием по скорости |
| `prefers-reduced-motion` | гасит CSS, но лента всё равно перелистывает тему 81–133 раза | лента не едет вообще |
| Кольцо таймера | растёт (боковым зрением читается как «время есть») | убывает, плавно, в один акцент |

Общее — идея двух таймеров и структура «Что? / И что? / Что дальше?».
Это сильное решение, и оно взято сознательно.
